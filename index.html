SolutionLab

ITMD 504 course project

Explore the right tech for a real need.

SolutionLab is a web app in progress. Its goal is to help someone describe a problem, review possible technology solutions, and plan a next step.

Early preview — features are still being built.

What is planned

  1. Describe a needEnter a goal and a few requirements.
  2. Review optionsSee possible approaches and why they may fit.
  3. Save a planKeep a result for later review.

This is a learning project. View the public GitHub repository for its source and progress.
